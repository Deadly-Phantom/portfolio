# Engineering Design Portfolio: ESC102

My engineering design portfolio for **ESC102 (Praxis II)**, Engineering Science, University
of Toronto, 2025–2026. It is a single self-contained web page.

## Contents

- **Position in Context:** my approach to engineering design, which is the lens for the
  rest of the portfolio.
- **Project summaries** with annotated process reflections:
  - Praxis I: Wrap Container
  - CIV102: Bridge Design
  - Praxis II: Climbing Tool
- **CTMFs**, colour-coded by strand: Frame, Diverge, Converge and Represent.
- **Final reflection** and references.

## Viewing

Open [index.html](index.html) in a browser. It needs no build step or dependencies, and
the figures are in [images/](images/).
